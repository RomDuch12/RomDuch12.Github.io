TauConvert

Conversion de dessins vectoriels

Convertis tes dessins AI, PDF, EPS, SVG et DXF en DXF, SVG, EPS, PDF ou PNG : en ligne, dans ton navigateur, ou avec le programme Windows et son menu contextuel.

Convertir en ligne

    Tout se passe dans ton navigateur : rien n'est envoyé. Les textes non vectorisés des PDF ne sont pas repris ; l'EPS est lu pour les tracés simples (moveto, lineto, curveto). Pour les fichiers complexes, CorelDRAW compris, utilise TauConvert pour Windows.

    TauConvert pour Windows

    La version réduite de TauDrive : conversion et menu contextuel seulement, sans gravure ni pilotage de machine.

    7 formats en entrée : DXF, SVG, PDF, AI, EPS, PS et CorelDRAW (avec Inkscape ou LibreOffice).
    5 formats en sortie : DXF, EPS, AI, SVG et PDF.
    Clic droit dans Windows : « Convertir en… » sur un ou plusieurs fichiers ; pose et retrait sans résidu.
    Texte et cotations DXF rendus en contours, calques éteints ou gelés écartés.
    Télécharger TauConvert 1.0.0 (Windows 64 bits, .zip) Toutes les versions

    Décompresse l'archive, puis lance TauConvert.exe. Aucune installation, aucun droit administrateur. Windows peut afficher un avertissement SmartScreen : le programme n'est pas signé.
